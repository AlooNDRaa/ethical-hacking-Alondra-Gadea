# 🔐 Ethical Hacking | Alondra Gadea

Repositorio de actividades, prácticas y entregables realizados durante el curso **Ethical Hacking**, desarrollado en el marco de **Hacker Women Council**.

El objetivo de este repositorio es documentar el aprendizaje y las prácticas relacionadas con **seguridad ofensiva, reconocimiento, análisis de vulnerabilidades y penetration testing (PENTEST)**.

## 📂 Actividades

| # | Actividad | Descripción |
|---|---|---|
| 01 | **Análisis y planificación del PENTEST: Aurora Market** | Análisis del caso, definición del alcance, metodología y planificación de una evaluación de seguridad ofensiva. |
| 02 | **Reconocimiento y análisis de un objetivo con Nmap** | Exploración de un objetivo mediante diferentes técnicas de Nmap para identificar puertos, servicios, sistema operativo y otra información relevante. |
| 03 | **Análisis y explotación de vulnerabilidades mediante SQL** | Desarrollo y documentación de ejercicios prácticos de SQL, incluyendo consultas, análisis de resultados y conceptos relacionados con la seguridad de bases de datos. |
| 04 | **Análisis de seguridad web con OWASP ZAP** | Exploración de una aplicación web, análisis del tráfico HTTP, identificación de alertas de seguridad y documentación de hallazgos, riesgos potenciales y recomendaciones de mitigación. |

---

## 🛡️ Temáticas

A lo largo del curso se trabajan conceptos y prácticas relacionados con:

- 🔎 Reconocimiento y análisis de objetivos.
- 🧪 Penetration Testing (PENTEST).
- 🕵️ Identificación y análisis de vulnerabilidades.
- 🗄️ Consultas SQL y seguridad de bases de datos.
- 🔐 Seguridad de aplicaciones.
- 🌐 Seguridad web y APIs.
- 📡 Análisis de solicitudes y respuestas HTTP.
- 📊 Evaluación y gestión de riesgos.
- 📝 Elaboración de informes técnicos de seguridad.
- 🛠️ Uso de herramientas de seguridad ofensiva, como Nmap y OWASP ZAP.

## ⚠️ Disclaimer

Este repositorio tiene fines **educativos y académicos**. Las técnicas, herramientas y procedimientos documentados deben utilizarse únicamente sobre sistemas para los cuales se cuente con la **autorización correspondiente**.

Los hallazgos identificados mediante herramientas automatizadas requieren análisis y validación adicional antes de considerarse vulnerabilidades confirmadas.
